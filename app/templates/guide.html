티메이트 사용 방법

골프 조편성, 이렇게 쉽게 끝내요

티메이트가 뭔가요?

골프 라운딩 조편성(조 짜기)을 쉽고 공정하게 해주는 무료 서비스예요. 참가자들이 같이 치고 싶은 사람 순서만 정하면, 모두의 희망을 최대한 반영한 최적의 조를 자동으로 만들어 줍니다. 앱 설치 없이 링크 하나로, 눈치싸움·제비뽑기 없이 깔끔하게요.

기본 3단계

  1. 1

    주최자가 구글 로그인 후 라운딩을 만들어요. (조 개수 · 마감 시간 · 참석자 명단) → 공유 링크가 생겨요.

  2. 2

    참가자는 링크만 열면 돼요(로그인 X). 본인 이름을 고르고, 같이 치고 싶은 순서대로 끌어서 정렬해 제출해요.

  3. 3

    마감 시간이 되면 그때까지 모인 희망으로 최적 조편성이 자동 확정되고, 모두의 화면이 결과로 바뀌어요.

👤 주최자가 할 수 있는 것

  • • 라운딩 만들기 — 조 개수, 자동 마감 시간(30분 단위), 참석자 명단
  • • 공유 링크를 참가자들에게 전달 (카톡 등)
  • • 내 희망순위 입력 — 주최자도 참가자라 같은 링크로 순위 제출
  • • 실시간 현황 — 누가 냈는지, 남은 시간, 미응답자 확인
  • • 명단 수정 — 이름 고치기·추가·삭제, 조 개수·마감 시간 변경
  • • 지금 바로 확정 — 마감 전이라도 즉시 결과 내기
  • • 결과에서 두 명 자리 바꾸기(수동 조정), 라운딩 삭제

🙋 참가자는 이렇게

  • • 받은 링크를 열고 명단에서 본인 이름 선택 (로그인 없음)
  • • 같이 치고 싶은 사람일수록 위로 끌어 순서를 정하고 제출
  • • 마감 전이면 언제든 순위 수정 가능
  • • 폰이 바뀌어도 링크 열고 이름 다시 고르면 이어서 OK
  • • 마감되면 링크에서 바로 최종 조편성 결과를 볼 수 있어요

⏰ 자동 마감 & 알림

첫 참가자가 순위를 낸 시점부터 마감 시간 카운트다운이 시작돼요. 시간이 되면 그때까지 응답한 사람 기준으로 자동 확정되고, 주최자에게 이메일 알림이 갑니다. (전원이 일찍 내도 마감 시간까지는 기다려요.)
